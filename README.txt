

This project is a photography portfolio website created using HTML, CSS, JavaScript, and Three.js. The website consists of three pages: a homepage with an interactive 3D camera model, a gallery where users can explore photographs in a 3D environment, and an About page with information about the photographer.

The goal of the project was to combine web development with interactive graphics to create a unique way of displaying photography.


- Three-page website
- Interactive 3D homepage
- First-person gallery navigation
- Hover and click interactions on gallery images
- About/Contact page
- Responsive navigation bar
- CSS Grid layouts
- External stylesheet
- Custom favicon

---

Technologies Used:

- HTML
- CSS
- JavaScript
- Three.js

Homepage:

- Click and drag to rotate the camera model.

Gallery:

| Key | Function |
|------|----------|
| W / ↑ | Move forward |
| S / ↓ | Move backward |
| A / ← | Move left |
| D / → | Move right |
| Mouse | Look around |
| Click | Interact with a photograph |
| Esc | Exit photo focus mode |


Steps to run this website:
Download all the images into a folder called Pictures, and the glb model onto a folder called Assets. Download all other files normally and open VScode. In VScode download an extension called Live Server and run the model off of the Live Server so that you can view the 3d elements on the Home and Gallery pages.
